# Summer Camp Checklists

We generally leave for summer camp on Sunday morning.


## For Parents

- [ ] Plan for Payment Schedules - the troop has to pay several months in advance. The price depends on where we go.
- [ ] Care Packages - make a shoebox sized care package with non-perishable items the week or two before summer camp. Give to Scoutmaster or Assistant Scoutmaster before leaving for the event.


## For Quartermaster

- [ ] first aid kit
- [ ] hatchet
- [ ] kindle cracker
- [ ] Camp Stove - for heating water and cooking one evening meal
- [ ] dutch ovens and gear
- [ ] charcoal
- [ ] propane
- [ ] emergency tarps for camp tents
- [ ] coffee
- [ ] ice chest

## Scoutmaster and Assistant Scoutmasters

- [ ] medicine lock box
- [ ] Medical forms - part A,B,C
- [ ] Did scouts take their medicine daily
- [ ] keys to the trailer(s)
- [ ] dutch oven competition plan
- [ ] scoutmaster merit badge requirements
- [ ] adult training opportunities
- [ ] Scout Schedule printouts
- [ ] All drivers have handheld radios
- [ ] care packages passed out Wednesday evening
- [ ] designated place to store fishing poles on the ride up so they are not broken


## Checklist if a scout needs to leave early

- [ ] Medicine returned
- [ ] gear packed


## Scouts

- [ ] plenty of socks, especially if wet weather is expected. Three extra pairs + one pair per day
- [ ] shower shoes
- [ ] soap
- [ ] towel
