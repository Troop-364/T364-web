# Summer Camp

## Lessons Learned

- Bring 10x12 tarps if staying in traditional scout camp tents. They often leak when it rains.

## Remote Work (Adults)

It is best to call the camp and see what they actually have.  Between talking to camp staff and internet research, actual conditions can be figured out.

- [ ] cell coverage
- [ ] dedicated remote work area
- [ ] power at campsite
- [ ] wi-fi at campsite

Ideally, it would be nice to setup remote work at the campsite, but rarely is this possible unless you bring your own satelite internet and battery pack or generator.

If you can work using basic laptop, you will probably be ok, but often to do deep work, multiple monitors are needed, which often means power is needed. In my experience campsites have either power or internet, but never both.

More and more battery packs are showing up at camp. They support A/C power and some can run a laptop with extra monitor for several days.

Generators, must be the super quiet generators and don't expect to run them all the time. They are quieter, but not silent and not everyone want to hear them.
